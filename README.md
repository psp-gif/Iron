# Iron 1.0

Учебный магазин готовых компьютеров на Flask. Интерфейс на русском.

## Запуск на Ubuntu

Распакуйте папку iron и откройте её в VS Code. В терминале этой папки:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Если venv не установлен: `sudo apt install python3-venv`.
Откройте http://127.0.0.1:5000. Остановить сервер: Ctrl+C.
Выберите в VS Code интерпретатор `.venv/bin/python`.
В новом терминале повторите активацию окружения.

## Что работает

Главная, каталог из 8 примеров, поиск, фильтры, сортировка, карточки,
корзина с количеством и удалением, сохранение корзины в браузере,
выдвижное меню, тёмная и светлая темы, адаптивность и анимации.

## Границы версии

Цены демонстрационные: не сверены по Казахстану. Спецификации неполные,
материнская плата и БП уточняются. SVG — условные иллюстрации, не фотографии.
ИИ, регистрация, БД, реальная оплата, выкуп и отправка заказов не подключены.
Каталог — учебные данные, а не предложение реального магазина.
Не используйте `flask run --debug` при открытии публичного доступа.
Версия предназначена для локальной демонстрации.

## Что где происходит

* `app.py`: маршруты Flask и форматирование цены.
* `catalog.py`: список словарей с данными ПК.
* `templates/base.html`: общий каркас, меню и подключение ресурсов.
* `templates/home.html`: главная; `_cards.html`: повторяемая карточка.
* `templates/catalog.html`: каталог; `product.html`: подробности ПК.
* `templates/cart.html`: контейнер, который JS заполняет товарами.
* `templates/assistant.html`: честная заглушка будущего чата.
* `templates/info.html`: демонстрационные условия.
* `static/css/style.css`: темы, сетки, адаптивность, эффекты.
* `static/js/main.js`: меню, тема, уведомления, появление блоков.
* `static/js/catalog.js`: поиск, фильтры, сортировка.
* `static/js/cart.js`: корзина и запрос каталога через fetch.

## Пять вещей для защиты

1. Браузер запрашивает адрес, Flask выбирает функцию по маршруту.
2. render_template передаёт данные в HTML-шаблон Jinja.
3. CSS оформляет страницу; JS реагирует на действия пользователя.
4. localStorage хранит номера товаров и количество на одном браузере.
5. fetch('/api/products') получает JSON — данные, а не HTML-страницу.

## Практика

Измените описание Iron Pulse в catalog.py и перезапустите сервер.
Измените --accent в style.css и обновите страницу.
Покажите разницу между фильтром назначения и состоянием Новый / Б/у.
